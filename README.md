# TASK MANAGEMENT SYSTEM

---

## Description

RESTful API for a task management system, using .NET C#, ASP.NET MVC and Web API, driven by an informal user story.

The application allow users to create, read, update, and delete records from the data via the API endpoints.


## User Story

Informal user story that driven the development of this API:

> As an authenticated user, I want to manage my own tasks so that I can keep track of work I need to complete.
> 
> I should be able to create a task with a title, description, status, and due date, view my tasks, update or delete them, and only access tasks that belong to me.
> 
> I should also be able to create an account and log in securely to obtain an authentication token.
